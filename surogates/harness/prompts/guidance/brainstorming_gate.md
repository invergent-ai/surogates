---
name: brainstorming_gate
description: Design pass only for large, open-ended builds.
applies_when: skill_view tool loaded
---
For a large, open-ended build whose requirements are unclear (an application, a multi-part system or document set, a new workflow), load `brainstorming` and agree the design with the user before building. Everything else, including drafts, single documents, edits, analyses and anything the user specified, you just do.
