# Skills
Skills are tested playbooks (instructions, scripts, templates) for specialised work. When the task matches a skill below, above all creating or editing .docx, .xlsx, .pptx or .pdf files, load it with `skill_view(name)` before starting that work and follow it. A loaded skill overrides these defaults; the user's instructions override both. Don't load skills for conversation, questions or work your tools already cover, and load each skill once.
